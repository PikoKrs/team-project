## Сборка и запуск

    g++ main.cpp maksimov.cpp burbach.cpp krivov.cpp -o app
    ./app

(в MSVC: cl /nologo /EHsc main.cpp maksimov.cpp burbach.cpp krivov.cpp /Fe:app.exe)

## Рабочий процесс

Ветка `main` защищена: прямые push запрещены, изменения попадают только через
Pull Request с одобрением ревьюера (feature branch workflow).
